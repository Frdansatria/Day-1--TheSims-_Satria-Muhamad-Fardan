## Dokumentasi Kegiatan Workshop Day 1

### Rangkuman Materi
Sesi workshop membahas dua kemampuan utama untuk produktivitas. Bagian pertama membahas Prompt Engineering, yaitu teknik menyusun instruksi untuk AI agar memberikan hasil yang relevan dan tepat. Bagian kedua membahas sistem version control pakai Git buat mencatat setiap perubahan file di komputer lokal, serta GitHub sebagai platform kolaborasi berbasis web.

### point point penting yang ada di workshop 
* Perintah ke AI yang bagus itu sebaiknya punya 4 bagian kayak Role, Task, Konteks, dan Format
* AI menjawab jauh lebih pas dan nyambung kalo kita memberikan konteks yang jelas saat bertanya
* Urutan kerja di Git itu ada 3 langkah, tempat kita mengedit file Working Directory, tempat persiapan file sebelum dikunci atau Staging Area, dan tempat file disimpan permanen Repository
* Perintah dasar Git yang paling sering dipakai adalah `git init` buat wadah baru, `git add` memilih file, `git commit` menyimpan file, serta `git push` dan `git pull` kirim atau ambil file di GitHub
* Cara menyambungkan laptop ke akun GitHub sekarang lebih aman dan gampang menggunakan kunci rahasia bernama SSH Key, dibanding sekadar memakai password biasa
